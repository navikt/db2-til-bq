class_table.py

Oppsummering

Beskriver tabelltypene og bygger DB2-spørringer, bind-parametere og BigQuery-lastkonfigurasjon. Se kildefilen.

Klasser

  • TableType skiller DIM og FAK.
  • BaseTable er abstrakt fellesklasse.
  • DimTable er dimensjon med full last.
  • FakTable er faktatabell med inkrementell last.
TableType

Enum brukt ved opprettelse av DimTable og FakTable, ved valg av uttrekk i db2_to_bq() og ved filtrering i init_OS.py. Ingen egne metoder.

Arver fra: Enum.
